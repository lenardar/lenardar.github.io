猫咪也玩传奇？

2026-11-28 折腾 约 7 分钟

虽然没玩过正版传奇，但我一直觉得传奇类似的游戏很好玩，感觉好像在游戏中扮演了一种不同的人生，但是这种游戏一般都氪金比较严重，于是乎我决定自己搭一个可以完全由自己掌控的游戏——猫猫版的传奇！

当然这个浏览器打开就能玩的手绘风猫咪 RPG 靠我手写肯定不可能一天完工的，我找了两位强力的 Agent 帮手，具体是谁我就不说了，目前游戏的全部代码包括1.68 万行原生 JS，没有使用任何前端框架哦，笑死，果然前端框架还是给人用的，Agent 一切手搓也毫无压力。

同时，我一如既往贯彻，能无服务器，绝对不用服务器的态度，这次的游戏也是完全运行在 Cloudfalre 上，下面且听我娓娓道来。

技术架构

如果说现在让我自己在服务器上写后端，我会优选 Rust，无他，Agent 帮助下写代码很简单，而 Rust 可以极大的节省我的服务器内存。但是不得不说 Rust 编译太麻烦了，要等半天，因此我果断选择了我的 Cloudflare 全家桶：

  • Workers
  • Workers AI
  • D1 SQLite
  • Durable Objects

实现槽点

其实每次版本都会发现很多 Bug，我觉得都挺好玩的，就都记录了一下，哈哈。

手感延迟

最早版本猫咪的移动以服务器计算为权威，因此会出现猫咪突然把拉回到原地的情况（虽然移动那么抽象，我们玩的还是很开心，哈哈哈）。

后面果断换了一个方案，猫咪移动发送在本地，然后汇报给服务器，只有异常移动才会被拉回到原地。

背包频闪

我们的背包物品如果被鼠标 hover，会显示具体的属性值，但是开始时部分物品一旦被 hover 会快速屏闪，导致物品丢弃很困难，非常影响体验。

针对这个问题，我排查半天才发现 CSS 权重问题，狠狠发力修复了 Bug。

移动失控

这个问题是猫咪移动时有时候松开按键会失控移动，并且移动键会无效。这个问题真的很火大，特别打 BOSS 时会变成固定八字，必须修复。

解决方案是只能在失焦时强制清空按键状态，同时改成同一轴上后按的方向键优先，顺手把网页文字选中和原生右键菜单也禁了。

数值失控

这个是最难崩的，一天改了三次经验曲线，有时候发现升级太快，游戏寿命太短，有时候发现升级太慢，游戏反馈不足，数值策划真的非常重要，哈哈哈。

游戏介绍

谈完了技术实现，下面我将隆重介绍我的游戏：

地图设计

游戏最核心的设定就是名字里的九条命：每只猫生来有 9 条命，如果 9 条命都用完了，再好的装备也会掉完，哈哈哈，其实还是很友好的。

整个世界以安全区「喵喵镇」为中心，往外分出两条越来越凶险的路线，地图结构也尽量做得各不相同：

  • 北线（陆地 → 地底）：先去新手村「边境 · 青草原」打田鼠、投果鼠、冲锋鼠，挑战「黄金鼠王 · 铁牙」；站稳脚跟后可以从青草原深处继续钻进「奶酪矿洞 · 地底迷宫」（26 级+），多层洞室里全是矿脉、炸药鼠、钻地鼠和「大矿主 · 钻头霸王」。
  • 南线（海岸 → 深海）：从主城南门去「咸鱼港 · 废弃码头」（14 级+），一边收拾毒鱼鼠、铁钩鼠和「独眼船长 · 咸鱼王」，一边还能在码头甩竿钓鱼；再往深处走就是沉在海底的「亚特兰蒂斯 · 沉没遗迹」（36 级+），这里特意做了氧气机制——下水后氧气持续往下掉。

战斗这块也加了不少细节（我的游戏都没有白玩），比如精英怪攻击前地上会先画红圈或扇形预警，Boss 打到半血会狂暴摇小弟。为了增加难度，一些怪物的伤害是百分比伤害，因此你等级在搞，如果不注意走位，还是很容易 go die 的。

升级路线

建号时有三个职业可以选（未来我要加入更多的职业，比如器械师？）：

  • 爪武者（近战血厚，Q 旋风爪推怪，E 九命狂怒开吸血爆砍）
  • 呼噜术士（远程输出，Q 呼噜声波减速，E 砸超级毛球群晕）
  • 罐头祭司（奶妈辅助，Q 开罐头给队友回血，E 插小鱼干图腾边奶边射）

通过打败老鼠可以获得经验升级，5 级开始每升一级给 1 点技能点，回主城找训练师「阿虎」就能点技能树，然后选择不同的路线强化技能。

武器目前有四种：

  • 近战单体最疼的鱼骨剑
  • 慢但砸地击退带晕的罐头锤
  • 射程超远的毛线弹弓
  • 飞出去再飞回来两段伤害的小鱼干回旋镖

装备一共四个格子：

  • 武器
  • 猫爪套
  • 项圈
  • 铃铛

品质上分普通、精良和带暴击/吸血/移速特性的金罐头，哈哈哈哈。

喵喵镇还设置了 NPC 铁匠「煤球」，在那里玩家可以用两件同款可以稳稳熔铸升星（最高 5 星，每星 ×1.15 属性增幅），还可以用命运猫爪抽一次奖（40% 升星、35% 不变、25% 掉星，血压拉满）。

同时每个装备还可以镶嵌宝石，总共有五种类型，三个相同低阶宝石可以合成一个高阶宝石。

我最巅峰的设计是磨爪石，可以提升装备等级，低等级装备可以选择使用这个道具至高升级至角色同级，避免低阶好装备后期变鸡肋。

组队副本

RPG 游戏当然离不开组队，我特别设计了组队功能，UI 设计上侧边能实时看队友血量、队内聊天，同时奖励上附近一起打怪可以共享经验。

每张野外地图里都藏着一个组队副本入口，每个组队副本有了若干房间，组队后可以通过打通一个一个房间，最终打到 Boss 房间，获取丰厚奖励。

娱乐功能

如果你以为战斗就完了，那你就大错特错了，作为村里最好的裁缝，我加入了大量的娱乐玩法：

  • 钓鱼与烹饪：玩家可以在咸鱼港甩竿钓鱼，或者在野外顺手采野浆果、鲜海带之类的东西，然后拿回主城找大厨「小灶」炖成炭烤小鲜鱼、海带鲜鱼汤、夜明珍珠露，战斗时吃这些食物可以获取许多增幅。
  • 家园系统：每只猫咪按一下 H 就能回家。园子可以通过小鱼干货币获得扩容，可以种猫草、鱼干花、猫薄荷、罐头瓜，撒速长肥和丰收肥，但是，好友也可以偷菜，哈哈哈（但是，买道具可以防偷菜）。同时，家园支持家具系统，可以摆猫爬架、鱼缸、小喷泉、毛线球、纸箱，自由装扮。

  • 喵乐园：最好的裁缝，必须把小游戏缝合进去。我在地图上还加了一个纯小游戏区域，里面有带排行榜和每日鱼干奖励的四台街机（喵喵消消乐、打田鼠、猫爪抓宝、喵喵捕鱼）、四张能跟真猫或老板招财下棋的五子棋桌（允许观众加入观战席，我好像下不过老板）、毛线球大战、你画我猜画室，甚至还整了一个露天影院，支持输入 B 站视频大家一起看。

  • 成就系统：目前做了 25 个成就，达成对应成就可以头上顶一个称号，哈哈哈。解锁成就以后，可以解锁一些时装，当然价格都不便宜。

写在最后
